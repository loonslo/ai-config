## 核心状态与失败行为

离线：选择来源 → 只读预览 → 明确范围 → 一致采集 → 完整性检查 → 接收映射 → 冲突决定 → 事务备份／写入／回读 → 已应用／加载未核验。取消在写入边界前生效；受管事务已经写入时不假称取消成功。来源或目标变化拒绝陈旧计划。受保护项或未选项不表示目标删除。扩展目标由其他工具链接管理时只保存配置库，明确显示原因。

云端：登录授权 → 账号确认 → 选择空间 → 解锁 → 本机包加密 → 分块上传／续传 → 云端确认保存 → 下载与解密 → 复用离线预览。父版本必须是实际基线；分叉双方保留。回执失败不会否定本机应用成功。不同服务器／账号／空间不得复用令牌或密钥。
