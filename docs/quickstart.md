# 备份 AI 助手

## 准备（只需一次）

安装 Python 3.11 或更高版本（建议 3.14），安装时勾选 **Add python.exe to PATH**。保留完整的 ai-config 文件夹。首次启动需要联网准备组件。

## 备份

Windows 双击文件夹里的 **备份.cmd**；Mac 双击 **备份.command**。按回车保留默认选择；输入编号可取消某个助手或工作文件夹，输入 `q` 可退出。核对说明后按回车开始。

完成后，窗口会显示备份文件的完整位置（通常在桌面）。原有文件会保留，也不会上传到网上。把这个 ZIP 复制到新电脑并妥善保管，其中有你的个人记忆。

## 恢复

恢复入口正在实现，请先保留完整备份文件。

如系统拦截启动，请记录提示并联系技术支持；当前尚未实测这些提示，放行步骤待补。双击、Mac 与零基础试用仍待验收。
