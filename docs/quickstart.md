# 用桌面客户端备份和恢复 AI 助手

维护日期：2026-10-08。当前为开发预览；真实跨机、助手加载和新手试用尚未验收。

## 旧电脑备份

1. 安装并打开 AI Config，进入「备份」。用户无需安装 Python 或 Git。
2. 勾选要备份的助手，添加核心工作文件夹；项目源码和数据需单独迁移。
3. 选择一个助手目录和项目目录以外的保存文件夹，点击「检查备份内容」。
4. 核对条目、排除项和提醒，点击「确认生成备份」。
5. 将结果页显示的 ZIP 自行复制到新电脑。备份可能含个人记忆，应妥善保管。

## 新电脑恢复

1. 安装所需助手，各启动一次后关闭；将项目文件单独放到新电脑。
2. 安装并打开 AI Config，进入「恢复」，选择自己的备份 ZIP，也可拖入窗口。
3. 点击「检查备份与本机差异」，选择要恢复的助手，为路径不同的项目选择新目录。
4. 安全设置、Codex 项目信任及 WorkBuddy 文本默认跳过；如需要，查看上列内容后勾选并重新检查。
5. 核对计划、冲突与跳过项，点击「确认恢复」。正在运行的助手会阻止恢复。
6. 已有不同内容默认保留，备份版本另存 `.from-bundle` 文件供对照；设置中的冲突字段可能跳过，结果页会列出。
7. 查看自动核验结果，重新登录、重装第三方技能、插件和 MCP 依赖，并在助手新会话里确认规则与记忆加载。

## 撤销

关闭相关助手，在「恢复记录」选择一次恢复，检查后「确认撤销」。若文件有后续修改，撤销会停止，保留现场。

真实恢复先在独立 Windows 用户或虚拟机中使用项目副本演练，见 [净室清单](machine-cleanroom-checklist.md)。文件写入和自动核验通过不代表助手已经加载。

旧 `.aiconfig` 文件不能当作本方案 ZIP 使用。旧命令入口及云端流程不属于当前产品。
