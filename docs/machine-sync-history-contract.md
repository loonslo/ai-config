# 历史流式包实施契约

维护日期：2026-10-09。细化 machine-sync-interfaces.md §11；实现与验收状态以 machine-sync-execution.md 为准。

- 未选择 history 时，不枚举或读取历史正文。范围为 Claude projects/*/*.jsonl、history.jsonl；Codex sessions/**、archived_sessions/** 下的文件、session_index.jsonl、history.jsonl。当前已接入 Codex 非 JSONL 文本及二进制文件，不再按扩展名排除。安全处理上限造成的排除仍须逐项报告，不能把排除数当作全部格式验收。数据库、凭据和链接不读。目录遍历有限，超过上限明确失败，不静默截断。
- JSONL 支持 UTF-8、UTF-16/UTF-32 LE/BE（BOM 或首部零字节布局识别），按编码单元对齐拆行，每行最大 1 MiB；逐行凭据扫描、默认占位符脱敏并复查 JSON。无效编码/JSON、超长行、跳过策略命中，整份不携带并记录原因。空行、BOM 和非命中字节保留。非 JSONL 内容不强制按 JSON 解析；同样逐记录扫描。跨行私钥整体隐藏（含正文），未闭合块隐藏到 EOF；私钥块超过 1 MiB 明确排除。发生脱敏的 .json/.toml 在最多 1 MiB 格式复查预算内解析，不合法或超出预算整份排除；此限制及超长无换行二进制仍是待扩展的边界。原文件不修改。命中行号清单每文件最多显示 2000 行、整个计划最多 20000 行；达到预算后仍保留每份文件提示，并提供实际已发现行数与截断标志；整份跳过策略在首次命中即停止，不宣称已扫描后续行。
- 历史包 format=ai-machine-history、schema_version=1，ZIP64 开启，manifest.json 最后写入。每段至多 1 MiB，默认每包数据至多 8 GiB、数据成员至多 20000、集合至多 64 GiB/128 包；每份 manifest 至多 16 MiB，全集 manifest 总字节至多 64 MiB；正文与元数据分别计量。测试可注入小阈值，单个原文件超过分包阈值也按连续段拆开。段不要求以换行结束，恢复按偏移重组原始脱敏字节。
- 每包包含 parent_content_id、set_id、part_index、part_count、段清单及该包 content_id。段含 source_id、agent、relative、offset、size、sha256、archive_path；归档路径使用不含原路径的编号。source_id 是 agent+相对路径摘要。集合 ID 由完整有序段描述决定，不随机改变。
- 主包 reports/history.json 保存相邻历史包的文件名、集合 ID、摘要与数量，不写主包自身 content_id，避免循环依赖；主包最终 content_id 注入历史包 parent_content_id。引用必须为同前缀、连续编号的 -历史-N.zip，同目录其他 ZIP 不能作为任意引用；允许主包另名而保持历史包名。只读预览不生成包；实际写入先排他创建暂存，复核来源、校验整组后发布。不能覆盖已有主包/历史包；历史分包先发布、主包最后发布；失败清理仅限本次拥有的暂存与发布文件。进程中断仍可能留下没有主包的历史分包，不能宣称跨文件系统原子提交。
- 校验采用有界流式读取，拒绝重复成员、越界路径、链接、非白名单历史路径、无效类型/摘要/偏移、过量成员/字节/manifest、压缩炸弹。必须验证同一主包、集合、连续序号、总包数和每个来源连续段；缺失或不匹配报 E7507。校验完成前不读写恢复目标。
- 恢复仅新增，不覆盖、不合并。Claude 项目转录按主包项目映射；未映射项目放报告目录 history-unmapped/。Codex 按原相对位置恢复；冲突使用唯一另存名。历史新文件纳入既有事务与撤销，写入也保持流式。历史未选择时不打开相邻历史包。
- 本契约不承诺助手可继续会话；界面和结果提醒“不保证可继续对话”。真实助手加载与跨机兼容必须单独验收。
