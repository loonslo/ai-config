## 已确认范围

负责人明确：云端继续冻结；只保留换机 ZIP 的原样备份恢复能力；桌面客户端为主且是唯一用户入口，命令行和问答脚本不作为交付方式。此决定取代 MACHINE-MIGRATION-TASKS.md 中桌面冻结、D15 与 D16 的终端入口限制，以及旧桌面 `.aiconfig` 流程。

## 模块与边界

- React 三页：备份、恢复、恢复记录。使用原生选择器选择 ZIP、保存目录和项目目录，支持将 ZIP 拖入窗口。
- 打包 Python sidecar 使用 MachineProtocol；只接受助手检测、ZIP 备份、ZIP 恢复、恢复记录和撤销。旧云端及 `.aiconfig` 请求被拒绝。
- application/machine_protocol.py 是界面适配层；复用 sync_core/machine 引擎，核心不依赖 React、云端或旧包模块。
- 预览不写入。确认使用有期限、一次性的计划，重新采集并比较输入；变化时停止。引擎继续负责源文件变化检查、事务备份、目标边界与进程门禁。
- 只使用 ai-machine-bundle ZIP，不将通用 ZIP 后缀注册为系统默认打开方式。旧 `.aiconfig` 关联从新构建配置移除；已经安装的旧版本关联是否残留需在升级实机验证。
- 安全设置、信任和 WorkBuddy 文本需在界面明确选择后重新检查。不同原文件保留，备份版本另存；结果页展示冲突、跳过、文件核验和人工事项。
- 用户无需 Python、Git 或终端。源码中的旧脚本与旧包库仅保留历史开发兼容，不被桌面主流程调用；不形成第二套交付流程。
